## Quick Task Reference

### Creating Walls

1. Select wall tool (Plan menu or toolbar)
2. Click to start wall
3. Click to set corners
4. Double-click to finish
5. Press Escape to cancel

**Tips:**
- Hold Shift for straight lines (0°, 45°, 90°)
- Double-click wall to edit properties
- Enter exact dimensions in properties panel

### Adding Rooms

1. Close all walls to form enclosed space
2. Rooms auto-detect from walls
3. Or manually draw room with room tool
4. Set floor/ceiling textures in properties

### Placing Furniture

1. Open furniture catalog (left panel)
2. Browse categories or search
3. Drag item to floor plan
4. Position and rotate as needed
5. Double-click to edit properties

### Adding Doors and Windows

1. Browse "Doors and windows" category
2. Drag to wall position
3. Item automatically cuts through wall
4. Adjust width and height in properties

### Creating Levels

1. `Plan > Add level`
2. Set floor elevation
3. Design each level separately
4. Use level selector to switch

### Setting Up Lights

1. Add light source from catalog
2. Position in room
3. Edit properties:
   - Power (intensity)
   - Color (RGB or Kelvin)
   - Light type

### Rendering 3D Image

1. Position 3D view camera
2. `3D View > Create photo`
3. Set quality and size
4. Choose rendering time
5. Click Create

## Troubleshooting Quick Fixes

| Issue | Solution |
|-------|----------|
| Object won't place | Check if room is defined, reset to floor level |
| Wall gaps | Zoom in and snap endpoints together |
| 3D view slow | Reduce furniture detail, close unused windows |
| Can't select object | Check if layer is locked, use Select All and filter |
| Rendering takes too long | Reduce quality, decrease image size |

## Plugin Quick Reference

### Essential Plugins

1. **Advanced Editing** - Precise object control
2. **Sweet Home Lights** - Professional lighting
3. **Wirings Plugin** - Electrical/plumbing layout
4. **AutoDimensioning** - Auto measurements
5. **Photo/Video** - Enhanced export

### Plugin Installation

```
1. Download .sh3p file
2. Double-click to install
   OR
   Copy to plugins folder:
   - Windows: %APPDATA%\eTeks\Sweet Home 3D\plugins
   - macOS: ~/Library/Application Support/eTeks/Sweet Home 3D/plugins
   - Linux: ~/.eteks/sweethome3d/plugins
3. Restart Sweet Home 3D
```
